# Politica de Privacidade - FarmaCheck

Ultima atualizacao: 2026-03-27

Esta Politica de Privacidade descreve como o aplicativo FarmaCheck trata dados no dispositivo e durante o uso de funcionalidades online.

## 1. Dados tratados

O FarmaCheck foi projetado para operar, principalmente, com armazenamento local no proprio dispositivo do usuario.

Dados operacionais registrados localmente:
- nome do produto
- codigo EAN/GTIN
- apresentacao, embalagem e medida
- validade, lote e observacoes
- quantidade e status de conferencia
- historico de alteracoes
- configuracoes locais (loja, regional, colaborador, preferencias)

## 2. Permissoes utilizadas

O app pode solicitar as seguintes permissoes, conforme o uso:
- Camera: leitura de codigo de barras (EAN/GTIN)
- Notificacoes: envio de lembretes e alertas locais

As permissoes sao solicitadas no contexto de uso da funcionalidade correspondente.

## 3. Armazenamento local

Os dados sao armazenados localmente no dispositivo usando SQLite e AsyncStorage.
Nao ha conta obrigatoria para uso do app.

## 4. Compartilhamento e exportacao

Quando o usuario exporta planilhas ou relatorios e utiliza o compartilhamento do sistema, os arquivos sao enviados somente para o destino escolhido pelo proprio usuario.

## 5. Integracoes externas

Quando um EAN nao e encontrado na base interna, o app pode consultar a API publica OpenFoodFacts para preencher dados do produto.
Nessa consulta, o codigo do produto e enviado ao servico externo para retorno das informacoes.

## 6. Coleta de dados pessoais sensiveis

O FarmaCheck nao foi projetado para coletar dados pessoais sensiveis, biometria ou localizacao precisa.

## 7. Seguranca

Sao adotadas medidas tecnicas razoaveis para reduzir risco de perda acidental de dados locais.
Como os dados ficam no dispositivo, a seguranca tambem depende dos mecanismos de protecao do proprio aparelho.

## 8. Direitos do usuario

O usuario pode:
- editar ou excluir registros no app
- apagar os dados locais pelo recurso de limpeza da base no aplicativo
- desativar notificacoes no app e/ou nas configuracoes do sistema

## 9. Alteracoes nesta politica

Esta politica pode ser atualizada para refletir melhorias do app, requisitos legais ou mudancas de plataforma.
A data de ultima atualizacao sera ajustada sempre que houver modificacoes relevantes.

## 10. Contato

Para duvidas sobre esta politica, disponibilize um canal oficial de contato do responsavel pelo aplicativo no cadastro da loja (Google Play).
